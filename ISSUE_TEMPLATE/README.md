# 🌿 Issue Templates

This folder holds the blueprints for our project's tasks and requests.

By adding Markdown templates to this folder, we can create guided forms that appear automatically when a team member clicks **New Issue**. 

**Future Templates we might place here:**
*   **Hardware Tracking:** For managing physical components like microcontroller boards, sensors, or wiring.
*   **Software Flow:** For tracking MicroPython or C# firmware development tasks.
*   **Documentation:** For tracking additions to our architecture or meeting notes.
