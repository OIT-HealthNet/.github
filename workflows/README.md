# ✨ Automation Workflows

This folder is the home for our **GitHub Actions**. 

When the project is ready, we can place simple YAML scripts here to quietly care for our repositories in the background. 

**Potential Automations:**
*   Auto-checking our MicroPython and C# code to ensure everything is perfectly formatted.
*   Verifying that our mesh network code compiles peacefully.
*   Automatically sorting new issues onto our GitHub Projects Roadmap.
